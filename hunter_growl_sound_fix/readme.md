此插件已停止更新，請使用
<br/>(L4D1) [l4d2_voice_mechanics_fix](https://github.com/fbef0102/Rotoblin-AZMod/blob/master/SourceCode/scripting-az/l4d2_voice_mechanics_fix.sp)

      * 這算是一個官方Bug
	* (安裝此插件之後) 修復上述的問題
