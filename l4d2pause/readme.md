# 中文說明
管理員可以強制暫停遊戲，也只有管理員能解除暫停

> __Note__ <br/>
此插件已停止更新，請使用
<br/>[l4d_pause](https://github.com/fbef0102/Game-Private_Plugin/tree/main/L4D_%E6%8F%92%E4%BB%B6/Server_%E4%BC%BA%E6%9C%8D%E5%99%A8/l4d_pause)

* 原理
	* 管理員輸入 ```!forcepause``` 強制暫停遊戲
	* 管理員輸入 ```!forcepause``` 解除暫停
	* 當發動暫停的管理員離開伺服器時，遊戲會自動解除暫停
