# Description | 內容
Fixed an issue where Survivors could use the chainsaw while reviving a teammate at the same time

* Apply to | 適用於
    ```
    L4D2
    ```

* <details><summary>How does it work?</summary>

    * (Before) Survivor can use chainsaw while reviving a teammate at the same time
    * (After) Unable to use chainsaw while reviving a teammate
        * Still hold the chainsaw but unable to attack
</details>

* Require | 必要安裝
<br/>None

# 中文說明
修正倖存者救人期間可以同時使用電鋸攻擊

* 原理
    * (裝此插件之前) 倖存者救人期間可以同時使用電鋸殺死周圍的殭屍或特感
    * (裝此插件之後) 倖存者救人期間無法使用電鋸
        * 電鋸依然拿在手上只是不能左鍵攻擊
